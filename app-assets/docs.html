EVERYDAY COOL · DOCUMENTATION

How the workshop works

Everyday Cool is a collection of interactive rooms — radios you can tune, benches you can build on, the night sky, maps, language, numbers — each one showing its working and saying plainly what it simplified. This app carries the whole collection in one installable program.

01Getting around

The hub is the front door: every room has a card there, and the search box at the top filters the cards as you type. The thirteen science workshops — Physics, Chemistry, Electronics, Measure, Body, the Radio Room, Engineering, Math, Earth, Computing, Sound, Time, and Light — gather behind The STEM Room card.

Links that stay inside the workshop open here in the app. Links that leave it — documentation sources, live services, downloads' home sites — open in your default browser, so the workshop stays exactly where you left it.

02Every room documents itself

Each room carries a Help ▾ menu in its own header. That menu opens the room's documentation right on the page: what each bench does, the honest simplifications behind it, and the safety lines where a room has them. The documentation section itself carries the same doors in every room — the full README, the room's source on GitHub, its sources & limitations, and a download of the room on its own. The full README for a room rides along inside the app as well, so the documentation works offline.

If you are stuck in a room, its Help menu is the first place to look — it was written for that room, not for the collection in general.

03Menus

  • File → Exit (on macOS, the Everyday Cool menu → Quit) closes the app.
  • Help → Documentation opens this page.
  • Help → Product Index opens the index of Steven Powell's products — Everyday Cool, Spectrum Search, the Travel Kit, and Steven Powell Tech Services — in your browser. A bundled copy also lives at products/index.html inside the app.
  • Help → GitHub Repository opens the Everyday Cool collection's source repository on GitHub in your browser — every room's code and writing, exactly as it ships here.
  • Help → About Everyday Cool shows the app name and version.

04Users & profiles

Several people can share one machine. Once more than one user exists, a profile picker opens at startup: pick your name, and the app restarts straight into your workshop. Each user keeps their own saved progress, preferences, and cache in every room — no room's code had to change for that.

The File menu shows the current user and carries Switch User and Add User. The data the app already had became the first user, "Default," adopted untouched. And File → Clear Cache clears only the current user's cached pages — never their progress.

05Online and offline

Most of the workshop runs fully offline inside the app — the benches, diagrams, and games are arithmetic and text. A few rooms use live data when you are online (the weather, the library catalogues, shared radios and station streams), and say so on their own pages. Nothing in the workshop sends your activity anywhere: the benches compute in your own window.

06Troubleshooting

A room is showing an old version of itself

Use File → Clear Cache. The app clears its cached pages, code caches, and service workers, then restarts with fresh copies of every room. Your room progress and preferences are not touched — they live in local storage, which Clear Cache deliberately leaves alone.

The app opens to a profile picker

That is profiles working as designed: more than one user exists on this machine. Pick your name and the app restarts into your workshop, with your progress where you left it.

A room asks for the internet

Some rooms are live by nature: weather forecasts, the library catalogues, radio streams and scanner feeds, map tiles and place searches, and fresh satellite orbit data all live on other people's servers. The benches and lessons around them still work offline; the room's own page says plainly which parts need a connection.

07Source & support

The same collection lives on the web at caeled.github.io/everyday-cool, and the app is built from it — what you see here is the collection itself, not a copy of a copy. Room pages there carry the same Help menus and documentation. The collection's own Documentation page rides along inside the app, too.

  • The collection's source: github.com/caeled/everyday-cool — every room, its writing, and its history.
  • This app's source: github.com/caeled/everyday-cool-app — the shell that carries the collection.
  • Found something wrong? Report an issue on GitHub — a room that misbehaves, a page that looks stale, a fact that needs correcting.
